# Afonin Web Studio

Сайт студии: React, React Router и Vite. Каждая страница на каждом языке собирается в готовый HTML, поэтому поисковики видят свой заголовок, текст и ссылки сразу, без выполнения JavaScript.

## Запуск

```sh
npm ci
npm run dev       # разработка, http://127.0.0.1:4173
npm run build     # сборка в dist со всеми страницами, 404.html и sitemap.xml
npm run preview   # проверка сборки: адреса и код 404 как на Vercel
```

## Адреса

Русский без префикса, английский и армянский с `/en` и `/hy`:

- `/` главная
- `/services`, `/services/websites`, `/services/automation`, `/services/webapps`, `/services/support` услуги
- `/work/telegram-support`, `/work/media-platform` портфолио
- `/privacy`, `/offer` документы

Старые адреса `/pricing*` постоянно перенаправляются на `/services*` (`vercel.json`). Список страниц и основной домен заданы в `src/routes.js`: при переезде на свой домен меняется `SITE_URL` там и адрес в `public/robots.txt`.

## Тексты

- `src/i18n/ru.js`, `en.js`, `hy.js`: тексты страниц, Title и Description (`seo`).
- `src/i18n/legal.js`: политика конфиденциальности и оферта.
- `src/seo.js`: canonical, hreflang, Open Graph и JSON-LD.

Цены на сайте не публикуются: посетитель оставляет заявку или пишет в мессенджер.

## Язык

Адрес `/` открывается на языке региона: Армения армянский, Россия и страны из списка в `src/i18n/LanguageContext.jsx` русский, остальные английский. Страну сообщает Vercel через `/api/geo`; если её нет, используется язык браузера. Язык региона стоит первым в переключателе. Выбор посетителя запоминается и важнее региона. Прямые ссылки на `/en` и `/hy` не перенаправляются, поисковые роботы тоже.

## Заявки

Форма отправляет заявку через `api/lead.js` в беседу Telegram. Если отправка не удалась, посетитель видит кнопки Telegram и WhatsApp с уже готовым текстом.

В Vercel (Project → Settings → Environment Variables):

| Переменная | Что это |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `TELEGRAM_CHAT_ID` | ID беседы менеджеров «Заказы» (вид `-1001234567890`); личный ID тоже подойдёт |
| `TELEGRAM_THREAD_ID` | необязательно: номер темы, если в группе включены темы |

Заявка приходит как «ЗАЯВКА LD-…» с контактом и кнопкой «WhatsApp» или «Написать в Telegram». Менеджер отвечает словом «беру», чтобы коллеги видели, что заявка занята.

Локально те же переменные лежат в `.env.local`.
